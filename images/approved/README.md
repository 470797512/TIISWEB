The last image was selected from the supplied photo library to show the campus
welcome desk. The remaining eight were explicitly linked in the review.

WebP files preserve the original composition. The HEIC was converted to JPEG
before WebP encoding. Each image has 1600px and 800px versions, encoded at quality
84 without embedded EXIF metadata. Originals remain in the local source archive,
outside the deployable website.

The retired library portrait was removed from the website and all six HTML
references. Do not restore it from repository history. For group photographs,
use the natural-ratio `.hero--photo` / `.photo--natural` frames in
`photography.css`, keeping captions outside the picture.
